# Task 2 - Customer Segmentation

## Objective

The objective of this task is to analyze customer data and identify different customer segments based on their purchasing behavior.

## Dataset

The dataset used for this task is `Online_Retail_1200.xlsx`.

The dataset contains retail transaction information that can be used to understand customer purchasing patterns and segment customers into meaningful groups.

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook / Google Colab

## Analysis Performed

- Data loading and inspection
- Data cleaning
- Exploratory Data Analysis
- Customer-level analysis
- Analysis of purchasing behavior
- Customer segmentation
- Data visualization
- Interpretation of customer segments

## Objective of Segmentation

Customer segmentation helps identify groups of customers with similar purchasing behavior. These segments can help businesses understand their customers and make better marketing and business decisions.

## Files

- `csa_data_set_task_2.ipynb` - Customer Segmentation analysis notebook
- `Online_Retail_1200.xlsx` - Dataset used for the analysis

## Conclusion

The customer segmentation analysis helped identify different groups of customers based on their purchasing behavior. The results can be used to understand customer preferences, identify valuable customer groups, and support data-driven marketing strategies.
