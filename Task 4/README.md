# Task 4 - Predicting House Prices with Linear Regression

## Objective

The objective of this task is to predict house prices based on different housing features using Linear Regression.

## Dataset

The dataset used for this task is `housing dataset for task 4.csv`.

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab / Jupyter Notebook

## Work Performed

- Data loading and inspection
- Data cleaning
- Exploratory Data Analysis
- Feature selection
- Train-test split
- Linear Regression model building
- Model prediction
- Model evaluation
- Actual vs Predicted price visualization

## Model Evaluation

The Linear Regression model was evaluated using:

- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
- R² Score

## Files

- `PHP_with_linear_regression.ipynb` - House price prediction notebook
- `housing dataset for task 4.csv` - Dataset used for the analysis
- `README.md` - Project documentation

## Conclusion

The Linear Regression model was used to predict house prices based on the available housing features. The project provided practical experience in data preprocessing, exploratory analysis, machine learning model building, prediction, and model evaluation.
